# Pixel art

Pixel art sent by contributors, as PNG files: `art/<pet>/<size>/<pose>.png`.
How to make and send one: [doc/contributing/pixel-art.md](../doc/contributing/pixel-art.md).

```bash
python3 -m bashou.art show art/fox/32/base.png   # preview it in your terminal
python3 -m bashou.art check                      # check the whole folder (CI does it too)
```
