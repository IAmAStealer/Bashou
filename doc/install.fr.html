Bashou : un compagnon de terminal qui apprend les commandes Linux

Bashou est un moyen gratuit et open source d'apprendre la ligne de commande Linux et les scripts bash, pour les débutants et au-delà. C'est un compagnon de terminal : un petit animal en pixel art vit dans le coin de ton terminal et grandit quand tu utilises de vraies commandes, te donne des astuces et t'explique ce que fait chaque commande. Il marche hors ligne, sans compte et sans IA. Le jeu est en français : bashou config language fr.

Code source et guide : github.com/IAmAStealer/Bashou (licence MIT).

Ce que tu apprends

  • Les commandes Linux : les fichiers, grep, find, les pipes, awk et sed, les permissions, les processus, les disques, les archives, les paquets avec apt et dnf, les services systemd.
  • Les scripts bash : les variables, les guillemets, $( ), les boucles, set -euo pipefail.
  • Et, si tu les choisis : les réseaux (IPv4, IPv6, DNS, TCP), git, gpg et pass, SQL, la CI/CD, Python, C et Rust.

Comment il t'apprend

  • bashou learn <commande> démonte n'importe quelle commande et explique chaque option.
  • Des leçons avec des dessins, sur un parcours qui va de ta première commande aux scripts.
  • Des combats dans un shell bac à sable : bats chaque menace avec le bon outil ; elle revient après 1, 7 et 30 jours pour que tu t'en souviennes.
  • Des projets à construire en Python, Shell, C ou Rust, une petite étape à la fois.
  • Une aventure avec des questions sur ce qui tourne mal et ce qu'il faut vérifier en premier, et un jeu rapide, bashou spot, pour reconnaître d'un coup d'œil une adresse IPv6, un hachage ou du base64.

Installer sur Debian, Ubuntu

sudo install -dm755 /etc/apt/keyrings
sudo curl -fsSLo /etc/apt/keyrings/bashou.asc https://iamastealer.github.io/Bashou/bashou.asc
printf '%s\n' 'Types: deb' 'URIs: https://iamastealer.github.io/Bashou/deb/' 'Suites: ./' \
  'Signed-By: /etc/apt/keyrings/bashou.asc' | sudo tee /etc/apt/sources.list.d/bashou.sources
sudo apt update && sudo apt install bashou

Installer sur Rocky, Alma, RHEL, Fedora

sudo curl -fsSLo /etc/yum.repos.d/bashou.repo https://iamastealer.github.io/Bashou/bashou.repo
sudo dnf install bashou

Puis ouvre un nouveau terminal

Ton compagnon est là. S'il n'y est pas (sur Debian et Ubuntu, certains terminaux ne lisent pas les réglages du système), lance :

bashou on

Ça ajoute une ligne à ton ~/.bashrc, et bashou off cache le compagnon. Les mises à jour arrivent avec le reste du système (apt upgrade, dnf upgrade). Les paquets et les données des dépôts sont signés avec la clé de Bashou : apt et dnf refusent tout le reste. Un autre Linux : installe avec git, voir le README.

Tes données restent sur ta machine

Bashou ne collecte rien : pas de compte, pas de télémétrie, pas de pub. Il compte les outils que tu utilises, garde ces compteurs dans ton dossier personnel et ne les envoie jamais nulle part.
